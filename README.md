# MachineLearningCVE

## Запуск

Из корня проекта:

```bash
python3 -m venv .venv
./.venv/bin/pip install -r requirements.txt
./.venv/bin/streamlit run app.py
```

После запуска открой в браузере:

`http://localhost:8501`

Если `.venv` уже создан, достаточно:

```bash
./.venv/bin/streamlit run app.py
```
